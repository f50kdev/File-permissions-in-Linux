# 🔒 Linux File Permission Management — Research Projects

## 📘 Project Overview
This project focuses on **updating and managing file and directory permissions** within the `projects` directory used by the research team.  
The main goal is to ensure that access levels correctly reflect the **authorization and security policies** of the organization.

Improper file permissions can lead to unauthorized access, data leaks, or accidental modification of important files.  
By configuring permissions properly, we strengthen both **data integrity** and **system security**.

---

## 🧠 Learning Objectives
- Understand how Linux permissions work (`r`, `w`, `x`)
- Apply the `chmod` command to modify permissions
- Manage access for **users**, **groups**, and **others**
- Enforce least-privilege principles across project files
